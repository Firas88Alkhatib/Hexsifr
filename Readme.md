# HexSifr

HexSifr is an experimental open-source operating system written in Rust.

The project aims to explore operating system design from first principles, with a focus on simplicity, correctness, and learning. It is being developed from scratch rather than as a Linux-based system.

### Requirements

- Rust
- QEMU
- KVM enabled environment

### Run

```bash
cargo run
```
